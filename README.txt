BELGACEM BOUHDIMA — PORTFOLIO SOURCE

1. Extract the ZIP and open index.html in a browser.
2. Open the folder in VS Code to make it yours:
   index.html — change the biography, projects, experience and contact links.
   styles.css — change the palette, typography and layout details.
   portfolio.js — controls the project filters.
   bootstrap.min.css — Bootstrap 5.3.3, included for local use.
3. Add your own project screenshots and links as you prepare them for publication.
4. For static hosting, upload the extracted files with index.html at the root.
   There is no build command. Check the page on your phone before sharing it.
